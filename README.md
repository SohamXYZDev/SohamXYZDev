### About
- **Location:** Kolkata, India.
- **Focus:** Low-latency web tools, automation pipelines, on-device ML.
- **Hardware constraint:** Everything built and benchmarked on a 2013 Pentium G2020 (4 GB RAM). If it doesn't run at 60fps on legacy hardware, it's bloatware.
- **Stack:** Python, TypeScript, WebSockets, Fast APIs, Whisper.cpp.
